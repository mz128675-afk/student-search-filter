# Student Search + Filter

Search students by name — cards update live as you type.

## Features

- Student cards built from a JavaScript array with `map()`
- Live search with `filter()` (case-insensitive via `toLowerCase()`)
- "No student found" message when nothing matches
- Responsive Bootstrap card layout

## Tech Used

HTML5, CSS3, Bootstrap 5, JavaScript (map, filter, events)

## How to Run

Open `index.html` in any browser. Type a name in the search box to filter the cards.
